# Rule: Always Update and Push to Repository

Whenever any code changes, fixes, tests, or modifications are made in the project:
1. Always stage all changed files (`git add .`).
2. Commit with a meaningful conventional commit message.
3. Immediately push the commit to `origin main` at `https://github.com/xRosieRose/InterDash.git`.
4. Never leave modified code uncommitted or unpushed at the end of a task or turn.
